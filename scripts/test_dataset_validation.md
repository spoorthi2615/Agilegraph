# Experimental Dataset Validation Protocol

This document outlines the testing protocols established in Sprint 79.1 to mathematically and structurally validate the datasets driving the AgileGraph research.

## 1. Schema Validation Test
1. Locate the master dataset configurations in `/data/schemas`.
2. Execute the Pyydantic model validation script: `python -m scripts.validate_schemas`.
3. **Verify**: The script must parse all `.json` (CBOM, TLS) and `.csv` (GNN features) files without emitting `ValidationError`s. 
4. **Why**: Ensures that raw inputs collected throughout the timeframe adhere strictly to the ontology defined in the dissertation.

## 2. Leakage & Split Validation Test
1. Load the exported `AgileGraph-GNN-Tensors` dataset.
2. Execute the intersection validation utility: `python -m scripts.check_leakage`.
3. **Verify**: The script must return a set intersection of `0` between the `train_repo_ids` and `test_repo_ids`.
4. **Why**: Ensures that the GNN model's accuracy metrics represent true zero-shot generalization capabilities rather than overfitting to known repository topologies.

## 3. Duplicate Detection Test
1. Iterate over the `AgileGraph-Code-Corpus` file manifests.
2. Calculate the SHA-256 hash of all collected files.
3. **Verify**: No two repositories share > 95% identical cryptographic files (which would indicate unauthorized forking inflating the dataset scale).

## 4. Class Distribution Statistics Check
1. Run the Pandas summarization script: `python -m scripts.generate_stats`.
2. **Verify**: The output confirms a sufficiently balanced dataset for machine learning. 
   - Ensure the minority class (`PQC-Safe`) represents at least 15-20% of the nodes to prevent model collapse.
   - If severe imbalance is detected, verify that focal loss or synthetic oversampling (SMOTE) parameters are explicitly documented in the GNN configuration layer.

## 5. Reproducibility Execution Test
1. Wipe the local `/data/processed/` directory.
2. Execute the end-to-end extraction pipeline on a 5-repository subset of the `AgileGraph-Code-Corpus`.
3. **Verify**: The exact same number of Nodes, Edges, and CBOM files are regenerated byte-for-byte as the previous run.
